# M2 human evaluation receipts

Only reviewed, sanitized receipts from real frozen production slates belong here. Each receipt must bind the exact deployed code revision configured for the evaluation run, policy SHA-256, checklist SHA-256, production environment, UTC observation time, and configured category registry. Human relevance grades must follow the reviewed rubric and preserve adjudication evidence outside this public repository. Never add owner identifiers, tokens, prompts, raw history, model responses, or fabricated grades.

The operational collector records aggregate model and fallback counts only. Automated random slate sampling and flagged-case capture are not implemented, so those qualification inputs remain missing until a reviewed collector produces bound, sanitized receipts.
