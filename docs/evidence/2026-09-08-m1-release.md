## Reproduction and auth navigation

`python scripts/verify_local_reading.py` requires an already running, migrated disposable local Supabase stack. It captures local bindings without printing them, refuses a non-loopback origin, and fails if any case skips or no tests execute. It never starts, resets, or targets production. The required database result is nine tests with zero skips.

The callback's Back to the digest link intentionally returns within the authenticated tab. The auth browser cases prove session continuity even without cross-tab messaging. Story, external, and settings-entry links retain new-tab protections. Opening the callback return in a new tab would break the supported session-storage fallback.
