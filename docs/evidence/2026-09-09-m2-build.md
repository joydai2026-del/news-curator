# News Curator M2 build record

Date: September 9, 2026 (America/New_York).

## Scope and current state

M2 is implemented on the prepared `feat/m2-discovery-lanes` branch, based on `4741a64744c35f98d9f14c1180470f9ccb766f95`. The approved reading-companion scope places M2 in the private signed-in hub. M1 learning remains separate and open. M3 through M5 are outside this change.

The sole Python engine generates Updates, Hot, Interested and Surprise, resolves overlap by the approved priority, applies source/topic/history constraints, preserves secondary reasons and checks the seven edition bands. The protected materializer fetches the actual configured owner's profile and database history itself. Only a replay-verified PASS can become a stored private edition. Browser and agent CLI read the same owner-only edition RPC. Public publication entries never receive personal lane assignments.

Normal edition policy is configurable in `config/discovery-policy-r2.yaml`; frozen r1 is unchanged. Storage, staleness and retained-history policy is configurable in the database within the common client safety envelope. The workflow feature flag remains off by default. This branch has not been deployed, and no real account or production database was changed during the build.

Updates requires changed publisher text on the same canonical URL and source route across bound captures. Hot measures independent-source coverage with distinct publication times, not audience popularity. Surprise requires qualified publisher evidence, wider independent coverage, freshness, weak interest matching and absence from the supplied history. The retained history window is explicit; this is not a claim of all-time novelty.

## Remaining acceptance gate

The intended end state is an owner opening a settled, private, balanced four-lane edition with working read/save/history behavior. The implementation and controlled runtime tests establish the build path. Acceptance still requires a genuine owner-bound PASS edition, controlled release of the migration and feature flag, and live owner verification.
